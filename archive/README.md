# archive/

This directory will hold a read-only archive of superseded code — the versioned `final_experimentations/v1..v8` chain, `legacy*` copies, and `code_for_website/*` duplicates — each with a manifest row recording its origin path, what superseded it, and how to run the archived copy. Nothing under `archive/` is imported by live code; it exists to preserve research provenance while the canonical implementation lives in `npdl/`.
